🌤 About WeatherPro

A modern weather forecasting application built with Flask and the Open-Meteo API.

🌦️

WeatherPro v2.0

WeatherPro delivers accurate weather forecasts through a clean, responsive, and modern interface. It demonstrates API integration, Flask development, and an elegant user experience.

✨ Features

🌤 Current Weather
📅 7-Day Forecast
🕒 Hourly Forecast
⭐ Favorite Cities
🕘 Search History
🌅 Sunrise & Sunset
💧 Humidity
🌬 Wind Speed
🌡 Atmospheric Pressure

🛠 Technology Stack

Python Flask HTML5 CSS3 Jinja2 Open-Meteo API
